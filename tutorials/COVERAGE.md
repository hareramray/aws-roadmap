# Tutorial coverage register

[Tutorial index](README.md) · [How to use the lessons](START-HERE.md)

This register inventories the existing roadmap rather than claiming to enumerate every future AWS API. Each original chapter heading below has a tutorial route. Open the linked subject index for its more detailed topic-to-lesson mapping; related subtopics share worked exercises. Reference lists, questions, and templates are applied through the practice tutorials and remain linked to their original source.

Coverage is a learning-content map, not a statement that cloud resources have been deployed or that every specialist design was tested live.
